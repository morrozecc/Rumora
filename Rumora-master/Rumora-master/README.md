# Rumora Frontend

**Rumora** — стриминговый сервис для прослушивания музыки. Выполнено в качестве учебного проекта для университета. Приложение позволяет иметь свою коллекцию треков, ставить лайки и писать комментарии под треками, а так же просматривать чужие. Так же реализован удобный поиск по исполнителям и композициям. Пользователь может иметь три роли: Обычный юзер, Модератор и Администратор. У двух последних есть возможность редактировать треки и их содержание, а так же удалять чужие комментарии. Администратор дополнительно может назначать и отзывать роль модератора.
Приложение построено с использованием **React**, **TypeScript** и **React Router**, дизайн сделан в стиле популярных стриминговых сервисов. 

## Преимущества приложения

- Взаимодействие с бэкенд-частью приложения осуществляется через **REST API** 

- Роутинг настроен с помощью **React Router**.

- Наличие **авторизации** проверяется на любом роуте, при ее отсутствии пользователя перенаправляет на страницу авторизации.

- Формы регистрации и входа проходят строгую **валидацию**.
